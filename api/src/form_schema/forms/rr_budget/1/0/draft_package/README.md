# R&R Budget 3.0 draft package

This package is a source-pinned implementation canary. It proves that the native
Simpler form runtime can render the five nested/repeating structures and execute
the 30 calculation rules exactly resolved in the supplied runtime-rule evidence.
It also reconciles 20 source-resolved requiredness conditions to equivalent
required fields already present in the XSD-derived object structure.

It is not production-ready. Twenty-six source calculations remain blocked because
their operands were not resolved without inference. Other conditional behavior,
complete instructions/accessibility review, and XML submission fidelity remain open. The
draft is not eligible for published question-coverage metrics.
