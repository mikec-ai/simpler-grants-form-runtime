# R&R Budget 10YR draft package

This package is a renderable implementation canary, not a production form.

- Its 199-node structure and ten-period cardinality come from the pinned R&R Budget 10YR XSD.
- Its reusable budget behavior model inherits the source-bound family evidence used by R&R Budget.
- Thirty exactly resolved sums execute; 26 calculation candidates remain blocked.
- Exact target-form DAT behavior parity, instructions, accessibility, human acceptance, and legacy XML remain open.
- Semantic mappings are agent-proposed and cannot contribute to published coverage.
