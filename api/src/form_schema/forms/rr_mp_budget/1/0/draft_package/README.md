# R&R Multi-Project Budget draft package

This package is a renderable structural and calculation canary, not a production form.

- It extracts the standalone ten-period multi-project budget that was previously available only inside the Multi-Project Subaward Budget profile.
- It reuses the shared budget-family runtime while preserving source-specific cardinalities, including up to 100 key persons and 100 equipment entries per budget period.
- Ten sums have exact, source-resolved runtime evidence and are executable: per-period travel and indirect-cost totals plus eight cumulative summary totals.
- One exact same-row requiredness condition reconciles to equivalent XSD-derived required fields: an existing equipment row already requires both item and requested funds.
- The remaining 46 observed calculations and 54 observed conditions stay unresolved. They are not inferred from a similar budget form.
- Three typed attachment fields use the shared attachment validation projection.
- Semantic mappings remain agent-proposed. Legacy XML, complete policy and instruction review, accessibility, and human acceptance remain open.
- This package cannot contribute to published coverage and is not production-ready.
