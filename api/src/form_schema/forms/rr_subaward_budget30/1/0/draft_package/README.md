# R&R Subaward Budget 30 draft package

This package is a renderable composition canary, not a production form.

- It embeds up to 30 five-period R&R Budget profiles using the shared budget-family runtime.
- Thirty source-resolved sums execute independently within each subaward budget.
- Twenty source-resolved same-object requiredness conditions reconcile to equivalent XSD-derived required fields within each embedded budget.
- The 30 XSD fields named `ATT1` through `ATT30` remain hidden, unresolved technical wire slots. Their names and `xs:string` types are not treated as attachment proof.
- Target-form DAT behavior parity, 26 unresolved calculations, instructions, accessibility, human acceptance, and legacy XML remain open.
- Semantic mappings are agent-proposed and cannot contribute to published coverage.
