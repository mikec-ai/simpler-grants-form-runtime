# R&R Multi-Project Subaward Budget draft package

This package is a renderable structural canary, not a production form.

- It composes up to 30 ten-period multi-project budgets through the shared budget-family runtime and recursive FieldList UI.
- Its XSD-backed structure contains the same broad budget concepts as the R&R Budget family, but it preserves source differences such as multi-project cardinalities and constraints.
- The current pinned multi-project behavior evidence contains no calculation or conditional records. The package therefore does not inherit the 30 calculations executed by superficially similar R&R Budget forms.
- The 30 XSD fields named `ATT1` through `ATT30` remain hidden, unresolved technical wire slots. Their names and `xs:string` types are not treated as attachment proof.
- Behavior parity, instructions, accessibility, human acceptance, and legacy XML remain open.
- Semantic mappings are agent-proposed and cannot contribute to published coverage.
